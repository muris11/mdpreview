What is Markdown?

Markdown is a lightweight markup language created by John Gruber in 2004 for writing formatted text using plain, readable characters. Two asterisks around a word make it bold, hash marks at the start of a line make a heading, and the same plain-text file can render as HTML, a PDF, a Word document or a web page.

Because it is just text, Markdown travels everywhere: GitHub READMEs, pull request descriptions, README files, Obsidian and Notion notes, documentation sites, blog posts, release notes and chat messages. Learn it once and the syntax works in all of them.

Why use Markdown instead of a word processor

  • Plain text, no lock-in. A .md file opens in any editor and will still be readable in twenty years.
  • Diff-friendly. Version control can show exactly which sentence changed, because a change is a change of words, not of binary formatting.
  • One source, many outputs. The same file becomes a web page, a PDF, a README or an email without retyping.
  • Focus on writing. No toolbar, no font picker — just the words and a handful of symbols.
  • Renders everywhere. GitHub, GitLab, Stack Overflow, Discord, Reddit and most doc tools speak Markdown natively.

Markdown tables

Tables are a GitHub Flavored Markdown extension. The dashes build the column widths; you do not have to align them by hand, but keeping them tidy makes the source readable. 

| Feature        | Supported | Notes                    |
|----------------|:---------:|--------------------------|
| Live preview   |    ✅     | Debounced while typing   |
| Mermaid        |    ✅     | Lazily loaded            |
| KaTeX math     |    ✅     | Inline $ and block $$    |

Use :--- for left alignment, ---: for right alignment and :---: for centred columns.

Code blocks & syntax highlighting

Wrap code in three backticks and name the language after the opening fence. MDPreview Center highlights more than 30 languages, including JavaScript, TypeScript, Python, Go, Rust, Java, PHP, SQL, HTML, CSS, YAML and JSON. 

```js
// Fenced code block with a language tag
const greeting = "hello, markdown"
console.log(greeting.toUpperCase())
```

Use a single backtick pair for inline code — `slice(0, 8)` — so identifiers stand out from the prose around them.

Math with KaTeX

Inline equations use single dollar signs, display equations use double dollar signs. Both are rendered by KaTeX, so the output is fast, crisp and searchable.

$E = mc^2$ Inline equation inside a sentence
$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$ Centred display equation on its own line
$\sqrt{x^2 + y^2}$ Roots, fractions and subscripts all work

Mermaid diagrams

Draw flowcharts, sequence diagrams, class diagrams, gantt charts and more without leaving the document. Tag a fenced block mermaid and it renders as an image in the preview. 

```mermaid
flowchart LR
  A[Write Markdown] --> B{Preview}
  B --> C[Export PDF]
  B --> D[Share link]
```

Mermaid is loaded on demand, so documents without diagrams never pay for it.

Footnotes & task lists

Footnotes let you cite a source without breaking the sentence. Mark a reference with ^[1] style syntax and define it at the bottom of the document; the preview turns both into a linked note. 

Markdown was invented in 2004.[^gruber]

[^gruber]: John Gruber, "Markdown: Syntax".

Task lists turn bullets into checkboxes — ideal for release notes and README checklists: 

- [x] Write the document
- [x] Check the preview
- [ ] Share the link

Preview, share and export

Writing is only half the job — getting the document out is the other half. MDPreview Center covers every path a Markdown file usually takes.

How to convert Markdown to PDF

  1. Open the editor. MDPreview Center loads with a sample document. Paste your own Markdown over it, or drop a .md file onto the page.
  2. Check the preview. Headings, tables, code, math and diagrams render live in the right pane, so you catch layout problems before exporting.
  3. Download the PDF. Open the export menu and choose Download PDF, or press Ctrl/Cmd + Shift + S. The file is generated in your browser with page numbers and a footer — nothing is uploaded.

How to share a Markdown document

Press Ctrl/Cmd + Shift + K to open the share dialog. It offers two kinds of link:

Full link — stays private

The whole document is compressed with LZ-String and placed in the URL fragment after #. Fragments are never sent to a server, so the content leaves your browser only when you paste the link somewhere yourself. Best for private or sensitive documents.

Short link — easy to paste in chat

Create produces a compact /s/abc123 URL. Large documents are split into chunks behind a manifest and reassembled on load, with automatic retries when the paste service rate-limits. The compressed text is stored publicly until it expires, so use the full link when the document must stay private.

Other exports

  • Download .md — the original source file.
  • Download .html — a standalone page with the styles inlined, ready to host anywhere.
  • Copy rich text — paste formatted content straight into Google Docs, Word or an email.
  • Print — browser print dialog, use "Save as PDF".

Frequently asked questions

What is Markdown?

Markdown is a lightweight markup language invented by John Gruber in 2004 for writing formatted text with plain characters. Asterisks make text bold, hash marks make headings, and the same file renders as HTML, PDF, Word or a web page.

Which Markdown flavor does MDPreview Center support?

GitHub Flavored Markdown (GFM) — tables, task lists, strikethrough and autolinks — plus footnotes, anchor links, syntax-highlighted code fences, KaTeX math and Mermaid diagrams.

How do I convert Markdown to PDF?

Open the document in MDPreview Center, then choose Download PDF from the export menu or press Ctrl/Cmd + Shift + S. The PDF is generated in your browser with styling and page numbers.

How do I add a Mermaid diagram to Markdown?

Wrap the diagram source in a fenced code block tagged mermaid — three backticks, the word mermaid, the diagram code, then three closing backticks. The preview renders it as a real diagram.
